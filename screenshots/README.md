# Screenshots

Add your app screenshots here after running the app.

## Required Screenshots:
- `splash.png` — Splash/loading screen
- `login.png` — Login screen
- `register.png` — Register screen
- `home_empty.png` — Home screen (no tasks yet)
- `home_tasks.png` — Home screen (with tasks added)
- `create_task.png` — Create new task screen
- `edit_task.png` — Edit task screen
- `delete_confirm.png` — Delete confirmation dialog

## How to take screenshots from the Android Emulator:
Click the **camera icon 📷** on the side panel of the emulator window.
Screenshots are saved automatically to your Desktop or Downloads folder.
